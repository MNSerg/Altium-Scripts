# Открытые вопросы и принятые по умолчанию значения

Пока вы отвечаете, скрипты уже работают с указанными ниже значениями. Измените диалоги или напишите, что нужно поменять.

## 1. Скругления треков (`TrackCornerFillet`)

| Вопрос | Принято по умолчанию |
| --- | --- |
| Радиус скругления | **0,5 мм** |
| Нужно ли выбирать несколько сегментов трека? | **Да.** Скрипт обрабатывает все выделенные треки/дуги. Один сегмент без угла ничего не скруглит. |
| Если уже есть скругления | Один вопрос на весь запуск: «На выбранном треке уже есть скругления. Переделать их?» Да = удалить и поставить заново; Нет = пропустить вершины с существующими дугами. |
| T-образные стыки | Скругляется угол только если в вершине встречаются **ровно два выделенных** сегмента. Третья (невыделенная) ветка игнорируется. Три и более выделенных сегмента в одной точке — вершина пропускается. |
| Слишком большой радиус | Вершина пропускается, в конце показывается предупреждение. |

**Вопрос к вам:** нужен ли режим «радиус в % от короткого сегмента», как в примере Fillet, или достаточно фиксированного мм?

## 2. DXF-экспорт контуров (`DxfOutlineExport`)

| Вопрос | Принято по умолчанию |
| --- | --- |
| Какие слои отмечены в чеклисте | Все **медные** слои, шелкография, keep-out, Mechanical 1. Маска и паста — сняты, но доступны. |
| Площадки / переходные / полигоны | **Включены** (контуры, не заливки). |
| Формат концов трека | **Круглые** (дуга 180°), как у типичного IPCB_Track. |
| Единицы DXF | мм, ASCII DXF R12. |
| Текст / штрихи | Пропускаются (см. README). |

**Вопрос к вам:** нужен ли по умолчанию только copper, или сразу silk+mech как сейчас? Нужны ли отверстия площадок как отдельные окружности на каждом слое?

## 3. Панелизация (`Panelizer`)

| Вопрос | Принято по умолчанию |
| --- | --- |
| Ряды × столбцы | **2 × 2** |
| Зазор плата–плата (X и Y) | **2 мм** |
| Поле до края панели | **5 мм** |
| Ширина перемычки | **3 мм** |
| Радиус фрезы / скругления перемычек | **1 мм** |
| Стиль перемычек | **Фрезерованные перемычки (routed tabs)** с скруглением под радиус фрезы, не mouse-bites. |
| Механический слой общего контура | **Mechanical 1** |
| Массив плат | `IPCB_EmbeddedBoard`, если API доступен; иначе копирование контура. |

**Вопрос к вам:** нужны ли mouse-bites (ряд отверстий) как отдельная опция? Нужны ли реперные знаки и технологические отверстия панели?

## 4. Сброс / аннотация десигнаторов (`SchDesignatorReset`)

| Вопрос | Принято по умолчанию |
| --- | --- |
| Область | **Все листы проекта** (с подтверждением). Можно ограничить текущим листом. |
| Сброс | Опция «сбросить в `?`» (как Reset Schematic Designators). |
| Перенумерация | Позиционная: **слева направо, сверху вниз**. Префиксы (R, C, U…) сохраняются. |
| Заблокированные | Не трогаем, если API отдаёт lock / «Don't change». |

**Вопрос к вам:** нужен ли режим «первый свободный номер» вместо позиционного? Нужна ли синхронизация PCB после аннотации (ECO)?

## 5. BOM (`BomExport`)

| Вопрос | Принято по умолчанию |
| --- | --- |
| Формат | **CSV** (UTF-8 с BOM). Excel через API Altium не формируем — CSV открывается в Excel. |
| Группировка | **Comment + Footprint**; если есть Manufacturer Part Number — он тоже входит в ключ. |
| Столбцы | Designator, Quantity, Comment, Description, Footprint, Value, Manufacturer, Manufacturer Part Number, Supplier, Supplier Part Number. |
| Исключения | Graphical, Standard (No BOM), Mechanical (если не Fitted), DNP/DoNotFit/Fitted=False. |
| Сопутствующий файл | `.bom.settings.xml` с описанием настроек. |

**Вопрос к вам:** обязателен ли столбец Value отдельно от Comment? Нужны ли варианты (Variant) как фильтр?

## 6. Земляные полигоны (`GroundPolygons`)

| Вопрос | Принято по умолчанию |
| --- | --- |
| Имя цепи | **GND** |
| Зазор (clearance) | **0,2 мм** |
| Слои | Все **сигнальные медные** слои стека (не внутренние плоскости plane, если API отличает). |
| Стиль | **Сплошной (solid)**, restore planes включён. |
| Уже есть полигон этой цепи на слое | Спросить: заменить или пропустить. |

**Вопрос к вам:** лить ли полигоны и на внутренние plane-слои, или только signal? Нужен ли hatch?

## 7. Мастер новой PCB (`PcbWizard`)

| Вопрос | Принято по умолчанию |
| --- | --- |
| Размер платы | **80 × 50 мм** |
| Радиус скругления контура | **2 мм** |
| Крепёжные отверстия | **4** (по одному в каждом углу), чекбокс можно снять до одного. |
| Отступ отверстия от угла | **4 мм** |
| Диаметр площадки / отверстия | 6 мм / **3,2 мм** |
| Медные слои | **2** (Top+Bottom). 4/6 — если слои уже есть в стеке; скрипт не всегда может перестроить stackup. |
| Полигоны GND | Выкл. по умолчанию, опция в диалоге. |
| Полигон вскрытия маски | Выкл. по умолчанию. |
| Сетка | **0,25 мм** |

**Вопрос к вам:** нужен ли сразу keep-out по контуру в дополнение к board outline? Стандартный диаметр крепежа (M3)?

## 8. Расстановка десигнаторов (`PlaceDesignators`)

| Вопрос | Принято по умолчанию |
| --- | --- |
| Слой | Только **шелкография** (Top/Bottom Overlay по стороне компонента). Сборочный слой не трогаем. |
| Область | Если есть выделение компонентов — только они, иначе **все**. |
| Ориентация | 0° или 90°, читаемо снизу/справа; на нижней стороне зеркало шелкографии учитывается. |
| Высота текста | Сохранить существующую; в диалоге можно задать фиксированную (по умолчанию пусто = как есть). |
| Скрытые десигнаторы | Пропускаются. |

**Вопрос к вам:** нужно ли дублировать десигнаторы на Mechanical/Assembly? Что делать, если ни один кандидат не свободен — прятать или оставлять по центру?

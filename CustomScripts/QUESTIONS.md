# Решения (вопросы закрыты)

Ниже — согласованные ответы заказчика. Скрипты и диалоги приведены к этим значениям. Открытых вопросов нет; остаются только ограничения API.

## 1. Скругления треков (`TrackCornerFillet`) — отвечено

| Тема | Решение |
| --- | --- |
| Выделение | **Достаточно одного** сегмента/пути. Скрипт добирает состыкованный путь (степень 2). |
| Квадрат 4 сегмента | **4 скругления** (по одному на угол). |
| Уже есть скругления | Диалог: переделать или нет. |
| Радиус | Задаётся в диалоге, по умолчанию **0,5 мм**. |

## 2. DXF (`DxfOutlineExport`) — отвечено

| Тема | Решение |
| --- | --- |
| Медь | **Все** медные примитивы: треки, дуги, площадки, полигоны — как контуры LINE/ARC (не заливка, не нулевая осевая). |
| Отверстия | Отдельный слой DXF **HOLES**, сущности **CIRCLE**. Не смешивать с медью. |
| Шелкография | Отдельные слои Top Overlay / Bottom Overlay. |
| Чеклист по умолчанию | Медь вкл., silk вкл., HOLES вкл. |

## 3. Панелизация (`Panelizer`) — отвечено

| Тема | Решение |
| --- | --- |
| Массив | **Столбцы = 4, ряды = 2** (4×2, 8 плат). В UI: «Столбцы (X)» и «Ряды (Y)». |
| Зазор плата–плата | **2 мм** |
| Поле до края | **10 мм** |
| Перемычки | Стиль mouse-bite **без отверстий** (узкий web). Ширина **4 мм** (настраивается). |
| Радиус фрезы | Поле есть, по умолчанию **1 мм** (галтели стыка перемычки с контуром). |
| Общий контур | После массива — внешний контур вокруг всех плат с перемычками на мех. слое. |

## 4. Десигнаторы схемы (`SchDesignatorReset`) — отвечено

| Тема | Решение |
| --- | --- |
| Область | **Весь проект** (все листы). |
| Порядок | Altium **Down then Across**: сверху вниз по колонке, затем следующая колонка слева направо. Не Across then Down. |
| Сброс в `?` | Опция есть, по умолчанию выкл.; перенумерация и все листы — вкл. |

## 5. BOM (`BomExport`) — отвечено

| Тема | Решение |
| --- | --- |
| Формат | **Excel**: SpreadsheetML, файл **`.xls`**, без Excel COM. |
| Столбцы | Точно: `Comment`, `Designator`, `Description`, `Quantity`, `Value`. |
| Исключения | **Нет** — включать DNP, графику, NoBOM, механику. |
| Группировка | Comment + Value + Description (+ footprint внутри). Designator — склейка. |

## 6. Полигоны GND (`GroundPolygons`) — отвечено

| Тема | Решение |
| --- | --- |
| Цепь | **GND** |
| Форма | **Контур платы** |
| Зазоры | **Не задавать скриптом** — правила проектирования. Поля зазора в UI нет. |
| Слои | Все сигнальные медные, как раньше. |

## 7. Мастер PCB (`PcbWizard`) — отвечено

| Тема | Решение |
| --- | --- |
| UI | Всё настраивается во всплывающем окне. |
| Медь | **4 слоя** |
| Крепёж | **4 отверстия по углам** |
| Сетка | **0,1 мм** |

## 8. Расстановка десигнаторов (`PlaceDesignators`) — отвечено

| Тема | Решение |
| --- | --- |
| Слой | **Только шелкография** (Top/Bottom Overlay). |
| Область | Есть выделение компонентов → только они; нет выделения → **все**. Написано в диалоге. |

## Диалоги и картинки — отвечено

У каждого скрипта форма с параметрами и `TImage`. Картинки: `CustomScripts/images/<имя>.png`. Можно заменить файл своим рисунком. Если файла нет — подсказка в диалоге.

## Оставшиеся ограничения API (не вопросы)

- Перестройка layer stack 2/4/6 из скрипта ненадёжна — задавать стек в Layer Stack Manager.
- DXF: нет boolean-union overlapping меди; текст шелкографии не штрихуется.
- Панель: `IPCB_EmbeddedBoard`; шелкография массива может не копироваться.
- BOM: SpreadsheetML `.xls`, не `.xlsx` и не Excel COM.
- Вскрытие маски в мастере — заливка на solder, не правило площадок.
- Аннотация: ECO на PCB не запускается автоматически.

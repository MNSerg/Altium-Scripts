# CustomScripts — скрипты Altium Designer 20+

Набор из восьми скриптов DelphiScript для повседневных задач PCB/схемы. Примеры в репозитории (`!SCRIPTS`) не изменялись.

Параметры согласованы с заказчиком (см. [`QUESTIONS.md`](QUESTIONS.md) — вопросы закрыты).

## Установка

1. В Altium: **DXP / File → Run Script…** либо **File → Open Project** и откройте `CustomScripts.PrjScr`.
2. Можно добавить проект в **Installation → Scripts** (Preferences → Scripting System → Project Scripts), чтобы скрипты были в меню **DXP → Run Script**.
3. Запускайте процедуру **`Start`** нужного модуля (она же `_Start`).
4. Формы (`.dfm`) должны лежать рядом с соответствующими `.pas`.

Каждый скрипт самодостаточен: его можно запускать и без общего проекта, указав файл `.pas`.

Интерфейс диалогов и сообщения — на русском. Идентификаторы в коде — на английском.

## Скрипты

### 1. Скругления углов трека — `TrackCornerFillet.pas`

**Назначение.** Ставит скругления (fillet, `IPCB_Arc`) заданного радиуса на все углы выделенного трека (цепочки сегментов `IPCB_Track`).

**Как запускать.** Откройте PCB, выделите **один сегмент или весь путь**, DXP → Run Script → `TrackCornerFillet.pas` → `Start`. Скрипт добирает состыкованный путь той же цепи/слоя (степень 2 в вершине). Квадрат из 4 сегментов даёт **4 скругления**. T-стыки не расширяются.

**Параметры.** Радиус в мм (по умолчанию **0,5**). Если на пути уже есть дуги в углах, один раз спрашивается: «переделать?»

**Поведение.** Угол — вершина с ровно двумя сегментами. Существующие скругления: Да = переделать; Нет = пропустить. Слишком большой радиус — вершина пропускается с предупреждением.

**Ограничения.** Не скругляет стык трек–дуга, если дуга не является скруглением между двумя треками. Не работает с `IPCB_Connection` (крысы).

### 2. DXF контуров слоёв — `DxfOutlineExport.pas`

**Назначение.** Экспорт выбранных слоёв PCB в DXF: геометрия — **линии и дуги полного контура**, не залитые полигоны и не осевые линии нулевой ширины.

**Как запускать.** PCB документ активен → Run Script → `Start`. Чеклист слоёв, OK, файл `.dxf`.

**По умолчанию отмечены:** все медные слои; Top Overlay / Bottom Overlay; отдельный слой **HOLES**. Keep-out, механика, маска, паста — в списке, но сняты.

**Что экспортируется.**

| Примитив | Как рисуется в DXF |
| --- | --- |
| Трек / дуга-трек | Контур ширины (LINE + ARC), не центрлайн |
| Площадка | Контур формы на медном слое |
| Переходное | Внешнее кольцо на меди |
| Заливка / регион / полигон | Только контур LINE/ARC |
| Отверстия площадок и переходных | **CIRCLE** на слое DXF `HOLES` (не смешиваются с медью) |
| Шелкография | Отдельные слои Top Overlay / Bottom Overlay |
| Текст | Пропускается |

Единицы — мм. ASCII DXF R12. Файл пишется скриптом напрямую, **без** `ExportDXF` Altium.

**Ограничения.** Сложные регионы с вырезами могут быть упрощены до внешнего контура. 3D тела не экспортируются. Boolean-объединение overlapping-геометрии не выполняется. Штриховой текст шелкографии не обводится.

### 3. Панелизация — `Panelizer.pas`

**Назначение.** Новый `.PcbDoc`, массив исходной платы, перемычки и **общий контур вокруг всех плат с перемычками** на механическом слое.

**Параметры по умолчанию**

| Параметр | Значение |
| --- | --- |
| Столбцы (X) × ряды (Y) | **4 × 2** (8 плат) |
| Зазор плата–плата | **2 мм** |
| Поле до края панели | **10 мм** |
| Ширина перемычки (web) | **4 мм** |
| Радиус фрезы / скругление стыка | **1 мм** |
| Стиль перемычек | Mouse-bite **без сверловки**: узкая перемычка, отверстия не сверлятся |
| Механический слой контура | Mechanical 1 |

Массив: `IPCB_EmbeddedBoard`. Перемычки — треки/дуги без ряда отверстий.

**Ограничения.** Embedded Board Array в скриптах AD не всегда копирует шелкографию панели. Сложный непрямоугольный контур исходной платы копируется ограничено.

### 4. Сброс и обновление десигнаторов схемы — `SchDesignatorReset.pas`

**Назначение.** Перенумерация **всего проекта** (все листы). Порядок Altium **Down then Across**: сначала колонка сверху вниз, затем следующая слева направо (не Across then Down). Счётчики префиксов общие на проект (R1 не начинается заново на каждом листе).

**Параметры.** По умолчанию: перенумеровать + все листы. Опция сброса в `?` выключена, но доступна. Заблокированные десигнаторы не меняются.

**Ограничения.** ECO на PCB автоматически не выполняется. Мультиканальность: могут понадобиться Compile + Annotate в GUI.

### 5. Выгрузка BOM — `BomExport.pas`

**Назначение.** BOM в **Excel** без Excel COM: SpreadsheetML 2003 XML, файл **`.xls`**, Excel открывает его нативно.

**Столбцы точно в этом порядке:** `Comment`, `Designator`, `Description`, `Quantity`, `Value`.

**Состав.** **Все** компоненты: DNP, графические, NoBOM, механические — ничего не исключается.

**Группировка.** Ключ Comment + Value + Description (footprint учитывается внутри, отдельного столбца нет). Designator — склейка списка.

Рядом пишется `*.bom.settings.xml`.

**Ограничения.** Это SpreadsheetML, не бинарный BIFF `.xls` и не `.xlsx`/COM. Вариант проекта — текущий; отдельный выбор Variant в диалоге не делается.

### 6. Земляные полигоны по контуру — `GroundPolygons.pas`

**Назначение.** Заливки (`IPCB_Polygon`) по **контуру платы** на всех сигнальных медных слоях, цепь **GND**.

**Зазоры скрипт не задаёт** — ими управляют **правила проектирования**. Поля зазора в диалоге нет.

Стиль по умолчанию — solid. Если полигон этой цепи на слое уже есть — спросить заменить/пропустить.

**Ограничения.** Внутренние plane-слои не заливаются как signal polygon. Если контура нет — bounding box. Rule Wizard не вызывается.

### 7. Мастер новой PCB — `PcbWizard.pas`

**Назначение.** Вся настройка в диалоге: размер, keep-out со скруглениями, крепёж, слои, полигоны GND, вскрытие маски, сетка.

**По умолчанию.** 80×50 мм, скругление 2 мм, **4 медных слоя**, **4 отверстия по углам**, сетка **0,1 мм**, отверстие 3,2 мм, отступ 4 мм.

**Ограничения.** Полная перестройка layer stack (2→4→6) через скрипт в AD20+ ненадёжна — стек лучше задать шаблоном / Layer Stack Manager. «Вскрытие маски» — заливка на Top/Bottom Solder по контуру, не правило Solder Mask Expansion площадок.

### 8. Авторасстановка десигнаторов на PCB — `PlaceDesignators.pas`

**Назначение.** Только **шелкография** (Top/Bottom Overlay). Если выделены компоненты — только они; **если выделения нет — все**.

Кандидаты: сверху/снизу/слева/справа от courtyard. Оценка коллизий. 0° или 90°. Скрытые можно пропускать.

**Ограничения.** Нет courtyard — используется `BoundingRectangleNoNameComment`. При плотной шелкографии остаётся лучший кандидат с предупреждением.

## Общие замечания по API

Используются только известные интерфейсы: `PCBServer`, `IPCB_Board`, `IPCB_Track`, `IPCB_Arc`, `IPCB_Pad`, `IPCB_Via`, `IPCB_Polygon`, `IPCB_Component`, `SchServer`, `ISch_Document`, `ISch_Component`, `Client` / `ResetParameters` / `RunProcess`.

Где API ненадёжен, сделан best-effort и описано ограничение — пустых заглушек нет.

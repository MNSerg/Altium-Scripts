# CustomScripts — скрипты Altium Designer 20+

Набор из восьми скриптов DelphiScript для повседневных задач PCB/схемы. Примеры в репозитории (`!SCRIPTS`) не изменялись.

## Установка

1. В Altium: **DXP / File → Run Script…** либо **File → Open Project** и откройте `CustomScripts.PrjScr`.
2. Можно добавить проект в **Installation → Scripts** (Preferences → Scripting System → Project Scripts), чтобы скрипты были в меню **DXP → Run Script**.
3. Запускайте процедуру **`Start`** нужного модуля (она же `_Start`).
4. Формы (`.dfm`) должны лежать рядом с соответствующими `.pas`.

Каждый скрипт самодостаточен: его можно запускать и без общего проекта, указав файл `.pas`.

Интерфейс диалогов и сообщения — на русском. Идентификаторы в коде — на английском.

## Скрипты

### 1. Скругления углов трека — `TrackCornerFillet.pas`

**Назначение.** Ставит скругления (fillet, `IPCB_Arc`) заданного радиуса на все углы выделенного трека (цепочки сегментов `IPCB_Track`).

**Как запускать.** Откройте PCB, выделите сегменты трека (и существующие дуги скруглений, если хотите их переделать), DXP → Run Script → `TrackCornerFillet.pas` → `Start`.

**Параметры.** Радиус в мм (по умолчанию 0,5). Если на выделенном пути уже есть дуги в углах, один раз спрашивается: «На выбранном треке уже есть скругления. Переделать их?»

**Поведение.**

- Угол — вершина, где встречаются ровно два выделенных сегмента одной цепи и слоя.
- T-ответвление не скругляется, пока не выделены обе стороны именно этого угла.
- Существующие скругления: Да = дуга удаляется, сегменты продлеваются до пересечения, ставится новая дуга; Нет = такие вершины пропускаются.
- Радиус больше, чем позволяет длина сегмента — вершина пропускается с итоговым предупреждением.

**Ограничения.** Не скругляет стык трек–дуга, если дуга не является скруглением между двумя треками. Не работает с `IPCB_Connection` (крысы).

### 2. DXF контуров слоёв — `DxfOutlineExport.pas`

**Назначение.** Экспорт выбранных слоёв PCB в DXF, где геометрия — **линии и дуги полного контура меди**, а не залитые полигоны и не осевые линии нулевой ширины.

**Как запускать.** PCB документ активен → Run Script → `Start`. Отметьте слои, OK, укажите файл `.dxf`.

**Что экспортируется.**

| Примитив | Как рисуется в DXF |
| --- | --- |
| Трек | Две параллельные линии на расстоянии width/2 и круговые крышки 180° |
| Дуга-трек | Концентрические внутренняя/внешняя дуги + радиальные/торцевые соединения |
| Площадка | Контур формы (окружность, прямоугольник, скруглённый прямоугольник, октагон) |
| Переходное | Внешнее кольцо (окружность) и отверстие |
| Заливка / регион / полигон | Только **контур** (LINE/ARC), без SOLID/HATCH |
| Текст | Пропускается |

Каждый PCB-слой → слой DXF с санитизированным именем. Единицы — мм. Формат — ASCII DXF R12 (ENTITIES: LINE, ARC, CIRCLE).

**Ограничения.** Сложные регионы с вырезами (islands заливки) могут быть упрощены до внешнего контура. 3D тела компонентов не экспортируются. Объединение overlapping-геометрии в один внешний контур не выполняется: каждый примитив даёт свой контур (корректная медная форма как объединение «стадионов»). Штриховой текст шелкографии не обводится.

Файл пишется скриптом напрямую, **без** `ExportDXF` Altium.

### 3. Панелизация — `Panelizer.pas`

**Назначение.** Создаёт новый `.PcbDoc`, размещает массив исходной платы, рисует контур заготовки и перемычки под фрезу с заданным радиусом, затем **общий контур вокруг всех плат с перемычками** на механическом слое.

**Как запускать.** Удобно из любого PCB. В диалоге укажите исходный `.PcbDoc`.

**Параметры по умолчанию.** 2×2, зазор 2 мм, поле 5 мм, ширина перемычки 3 мм, радиус фрезы 1 мм, Mechanical 1.

**Поведение.** Используется `IPCB_EmbeddedBoard` (как в примере panel-generator). Контур панели и перемычки рисуются треками/дугами. Общий контур — замкнутая линия на выбранном механическом слое.

**Ограничения.** Embedded Board Array в скриптах AD не всегда копирует шелкографию панели; для CAM обычно берут контуры. Mouse-bites не сверлятся (только routed tabs). Сложный непрямоугольный контур исходной платы копируется ограничено — берётся bounding box + board outline, если доступен.

### 4. Сброс и обновление десигнаторов схемы — `SchDesignatorReset.pas`

**Назначение.** Сброс десигнаторов в `?` и/или позиционная аннотация (слева направо, сверху вниз) по всем листам проекта.

**Как запускать.** Откройте схему или проект. Run Script → `Start`. Подтвердите обработку всех листов.

**Параметры.** Чекбоксы: сброс; перенумеровать. Префиксы R/C/U/… сохраняются. Заблокированные десигнаторы не меняются.

Сначала вызываются процессы Altium (`Sch:ResetDesignators` / аннотация), при неудаче — ручной обход `ISch_Component`.

**Ограничения.** ECO на PCB автоматически не выполняется. Каналы/мультиканальность: физические десигнаторы комнат могут потребовать Compile + Annotate в GUI.

### 5. Настройки и выгрузка BOM — `BomExport.pas`

**Назначение.** Собрать «правильный» BOM: уникальные строки, группировка Comment+Footprint (+MPN), количество, список десигнаторов, без чисто графических частей.

**Как запускать.** Из схемы или PCB (с PCB параметры тянутся по Unique ID источника).

**Выход.** `*.bom.csv` и рядом `*.bom.settings.xml`.

**Исключения.** Graphical, No BOM, DNP / Not Fitted.

**Ограничения.** Нативный `.xls` Altium BOM Report не создаётся (нет стабильного script API Excel). Откройте CSV в Excel. Варианты (Variants) — текущий проектный вариант, отдельный выбор варианта в диалоге не делается.

### 6. Земляные полигоны по контуру — `GroundPolygons.pas`

**Назначение.** Создать медные заливки (`IPCB_Polygon`) по контуру платы на всех сигнальных медных слоях, цепь GND (имя задаётся).

**Параметры.** Имя цепи (GND), зазор 0,2 мм, solid. Если полигон этой цепи на слое уже есть — спросить заменить/пропустить.

После создания вызывается `Rebuild` полигона, если метод есть.

**Ограничения.** Внутренние plane-слои (negative plane) не заливаются как signal polygon. Сложный контур копируется сегментами `BoardOutline`; если контура нет — используется bounding box. Правила зазора полигона в Rule Wizard не создаются — используется `ClearanceGap` полигона.

### 7. Мастер новой PCB — `PcbWizard.pas`

**Назначение.** Новая плата: размер, контур на Keep-Out со скруглениями, крепёжные отверстия (1 или 4), опции полигонов GND, число медных слоёв (best-effort), полигон вскрытия маски, сетка.

**Как запускать.** Run Script → `Start`. Можно из пустого PCB или скрипт создаст новый документ.

**По умолчанию.** 80×50 мм, скругление 2 мм, 4 отверстия M3 (3,2 мм) с отступом 4 мм, 2 слоя, сетка 0,25 мм.

**Ограничения.** Полная перестройка layer stack (2→4→6) через скрипт в AD20+ ненадёжна. Скрипт создаёт полигоны на существующих медных слоях и пишет в README, что stackup лучше задать шаблоном. «Полигон вскрытия маски» — регион на Top/Bottom Solder по контуру платы (открытие маски), это не правило Solder Mask Expansion для площадок.

### 8. Авторасстановка десигнаторов на PCB — `PlaceDesignators.pas`

**Назначение.** Разместить шелкографические десигнаторы снаружи корпуса, без наложений на площадки, треки, другие десигнаторы и отверстия.

**Как запускать.** PCB → Run Script → `Start`. Если компоненты выделены — только они.

**Эвристика.** Кандидаты: сверху/снизу/слева/справа от courtyard. Оценка коллизий. Ориентация 0° или 90°. Слой Overlay по стороне компонента. Скрытые пропускаются.

**Ограничения.** Courtyard, если слоя нет, заменяется `BoundingRectangleNoNameComment`. Сложные корпуса и плотная шелкография могут не найти идеальную точку — тогда остаётся лучший кандидат с предупреждением в отчёте.

## Общие замечания по API

Используются только известные интерфейсы: `PCBServer`, `IPCB_Board`, `IPCB_Track`, `IPCB_Arc`, `IPCB_Pad`, `IPCB_Via`, `IPCB_Polygon`, `IPCB_Component`, `SchServer`, `ISch_Document`, `ISch_Component`, `Client` / `ResetParameters` / `RunProcess`.

Где API ненадёжен, сделан best-effort и описано ограничение — пустых заглушек нет.

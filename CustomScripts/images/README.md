# Dialog pictures

Put BMP (preferred in Altium VCL) or PNG next to the scripts:

`CustomScripts/images/<name>.bmp`

Replace the file with your own drawing. Missing file = caption hint, no crash.

| DxfExport.bmp | DxfOutlineExport |

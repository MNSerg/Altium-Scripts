# Скрипты Altium Designer

Примеры сторонних скриптов находятся в папке `!SCRIPTS`.

**Новые рабочие скрипты** (скругления, DXF, панель, аннотация, BOM Excel, полигоны GND, мастер PCB, расстановка десигнаторов) — в папке [`CustomScripts`](CustomScripts/README.md). У каждого скрипта свой `.PrjScr` и процедура `Start…`. Картинки диалогов: [`CustomScripts/images`](CustomScripts/images/). Согласованные параметры: [`CustomScripts/QUESTIONS.md`](CustomScripts/QUESTIONS.md).

Требуется Altium Designer 20+.
